# Contributing to Control Panel Network

Thank you for your interest in contributing to projects under the
[Control Panel Network](https://github.com/Control-Panel-Network) organization.

Please also read:

- [Code of Conduct](CODE_OF_CONDUCT.md)
- [Security Policy](SECURITY.md)

## Getting started

1. Fork the repository you want to change (or use a collaborator clone).
2. Create a topic branch from the default branch (`main` unless the README says otherwise).
3. Make focused changes with clear commit messages.
4. Run the project’s documented checks (CI, linters, tests) before opening a pull request.
5. Open a pull request against the default branch and describe what changed and how you tested it.

## Pull requests

- Prefer small, reviewable pull requests
- Do not commit secrets, tokens, credentials, or private keys
- Do not paste live installer URLs that include temporary access tokens
- Update docs when behavior or setup steps change
- Expect CI to pass before merge

## Reporting bugs

Use GitHub Issues on the relevant repository for non-security bugs and feature ideas.

For security-sensitive findings, follow [SECURITY.md](SECURITY.md).
